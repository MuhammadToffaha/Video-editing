# Video-editing

Main repo for short-form video editing (Reels / TikTok / Shorts).

| Path | What |
|---|---|
| `skills/short-form-video-editor/` | Claude skill: captions + motion graphics + SFX + logo pipeline (SKILL.md, scripts, template, scene patterns) |
| `dist/short-form-video-editor.zip` | Packaged skill, ready to upload/install |
| `projects/glow-kbeauty-reel/` | First project: Glow Cosmetics K-beauty announcement (Egyptian Arabic, 57 s) incl. final `out/glow-kbeauty-reel.mp4` |

New video: follow `skills/short-form-video-editor/SKILL.md` (copy `template/` into `projects/<name>/`).
