# Video-editing

Main repo for short-form video editing (Reels / TikTok / Shorts).

| Path | What |
|---|---|
| `.claude/skills/Glow/` | Claude skill: captions + motion graphics + SFX + logo pipeline (SKILL.md, scripts, template, scene patterns) |
| `dist/Glow.zip` | Packaged skill, ready to upload/install |
| `projects/glow-kbeauty-reel/` | First project: Glow Cosmetics K-beauty announcement (Egyptian Arabic, 57 s) incl. final `out/glow-kbeauty-reel.mp4` |

New video: follow `.claude/skills/Glow/SKILL.md` (copy `template/` into `projects/<name>/`).

**Quick use:** open a Claude Code session on this repo, upload a video (+ optional logo image) and type `/Glow`. The skill runs the whole edit and sends back the finished mp4.
